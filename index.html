Kebijakan Privasi

Terakhir diperbarui: 13 Mei 2026

📋

1. Informasi yang Kami Kumpulkan

  • Nama dan email — untuk identifikasi akun.
  • Data transaksi keuangan — jumlah, kategori, catatan, dompet, tanggal.
  • Token FCM — untuk mengirim notifikasi push.
  • Rekaman suara — hanya saat fitur input suara aktif, diproses langsung tanpa disimpan permanen.
  • Foto struk — hanya saat fitur scan struk aktif.
⚙️

2. Cara Kami Menggunakan Informasi

  • Menyediakan fitur pencatatan dan analisis keuangan.
  • Memberikan notifikasi pengingat tagihan dan laporan mingguan.
  • Memproses input suara/teks ke AI untuk konversi otomatis menjadi transaksi.
  • Meningkatkan akurasi analisis dan rekomendasi keuangan.
📱

3. Izin Perangkat

  • Mikrofon — untuk fitur input suara. Rekaman hanya diproses saat pengguna menekan tombol rekam.
  • Kamera — untuk fitur scan struk. Foto hanya diambil saat pengguna memilih mode scan.
  • Notifikasi — untuk pengingat tagihan dan laporan keuangan.
  • Penyimpanan — untuk menyimpan laporan PDF.
🔒

4. Penyimpanan dan Keamanan

  • Data disimpan di server dengan enkripsi (HTTPS).
  • Password di-hash menggunakan bcrypt.
  • Token akses menggunakan JWT dengan masa berlaku terbatas.
  • Kami tidak menjual, menyewakan, atau membagikan data pengguna ke pihak ketiga.
🤖

5. AI dan OpenAI

Fitur AI (parse teks, chat keuangan, scan struk) menggunakan OpenAI API. Teks dan data transaksi yang dikirim ke OpenAI diproses sesuai kebijakan privasi OpenAI. Kami tidak mengirim data identitas pribadi (nama, email) ke OpenAI.

✅

6. Hak Pengguna

  • Mengakses data yang kami simpan.
  • Meminta penghapusan akun dan seluruh data terkait.
  • Menonaktifkan notifikasi kapan saja melalui Pengaturan.
📧 support@dompetku.app
🔔

7. Perubahan Kebijakan

Kami dapat memperbarui kebijakan ini sewaktu-waktu. Perubahan signifikan akan diberitahukan melalui notifikasi dalam aplikasi.
